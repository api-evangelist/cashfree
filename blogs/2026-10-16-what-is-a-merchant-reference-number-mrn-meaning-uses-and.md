Key Takeaways A Merchant Reference Number (MRN) is a unique identifier assigned by the merchant’s system to each transaction, used to track, reconcile, and reference payments internally. MRN is distinct from the payment gateway transaction ID, the bank reference number, and the UPI transaction reference; each serves a different part of the payment chain.
